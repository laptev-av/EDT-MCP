# Генерация форм и редактирование формы (и её элементов)

Issue: [#129](https://github.com/DitriXNew/EDT-MCP/issues/129)
План реализации: `git/plans_ai/129-form-tooling.md`
Справочник по разобранному API: `git/docs_api-edt/`

## Суть

AI-агент в EDT сможет создавать и наполнять формы сам, по текстовой команде — без ручного прохода по мастерам 1С.

## Что станет возможно

- **Генерация форм** одной командой: «создай форму элемента и форму списка для справочника Товары». Создаются стандартные формы (элемента, списка, выбора, группы) — как из мастера EDT, с реквизитами и модулем.
- **Наполнение форм** (этап 2): «добавь на форму поле Вес, группу Контакты и таблицу Товары» — поля, группы, таблицы, кнопки, надписи и реквизиты формы.

## Зачем это нужно

- **Экономия времени:** рутина «создать форму → разложить поля» уходит из ручной работы.
- **Сквозной сценарий:** агент собирает объект целиком — справочник, реквизиты, формы — за один диалог, без переключения на ручные действия в EDT.
- **Единый стиль:** формы строятся штатным механизмом платформы, поэтому результат корректный и привычный (без «самодельной» вёрстки).
- **Проверяемость:** после генерации агент сам сверяет результат через существующие инструменты (снимок/скриншот формы, проверка ошибок проекта).

## Риски и как они закрыты

- **Зависимость от версии EDT:** внутренний API форм меняется между релизами (подтверждено — сигнатура `generateForm` менялась: 8 → 9 параметров, версия пакета `3.1.0 → 4.0.0`). Заложена защита: вызовы изолированы за фасадом и переживают смену версии, а при несовместимости агент выдаёт понятную ошибку, а не «падает».
- **Поэтапность:** генерация форм (этап 1) проще и быстрее; наполнение элементами (этап 2) сложнее и идёт следующим шагом.
- **Задел зафиксирован:** весь разобранный API сохранён в служебной папке `docs_api-edt` с чек-листом проверки совместимости при обновлении EDT.

## Этапы

| Этап | Инструменты | Сложность |
|---|---|---|
| 1. Генерация форм | `generate_form` | Средняя |
| 2. Редактирование форм | `add_form_item`, `add_form_attribute` | Выше средней |

## Итог

Инструмент закрывает заметный пробел: раньше агент умел создавать объекты метаданных, но не их формы. После внедрения цепочка «создать объект → добавить реквизиты → сделать и наполнить формы» становится полностью автоматизируемой через AI, что ускоряет разработку и снижает долю ручных операций в EDT.
